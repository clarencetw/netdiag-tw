# 台灣固網報修與申訴流程

> 本文件**不記載客服電話號碼**，因為電話與服務時間會變動。請在報修當天，從下列官方管道查證最新資訊。整理日期：2026-11-02。

## 報修前先準備

1. 症狀：哪個服務、什麼動作、哪段時間、持續多久、是否每天重複。
2. 測試紀錄：`scripts/netdiag.py` 產生的報告，建議同時附上一般對照網站（`basic`）與台灣服務網站（`taiwan`）的對照結果，並註明有線或 Wi-Fi。
3. 基本資訊：用戶編號或電路號（帳單上有），不要在公開場合貼出。
4. 分享前遮罩公網／內網 IP、帳號與住址。

## 解讀對照結果（只是線索）

分組描述服務市場，不代表實際節點位置；CDN／anycast 可能讓不同市場網站由同地區提供服務。

| 現象 | 較可能的方向（仍需驗證） |
|---|---|
| 多組網站都慢或失敗 | 本地 LAN、Wi-Fi、DNS、VPN、安全軟體或上游；需其他裝置交叉驗證 |
| 只有某組網站慢，其他組正常 | 特定服務、CDN、解析或路徑差異；不能由分組判定國際出口／海纜 |
| 只有單一服務異常 | 該服務、CDN 或應用層 |
| 只有 Wi-Fi 異常 | 無線環境，先改用有線重測 |

## 報修與申訴順序

1. **向 ISP 報修**：到 ISP 官網或帳單查詢最新客服管道，請對方建立障礙單，並記下案件編號、受理時間與回覆方式。
2. **ISP 未處理或不滿意**：向主管機關國家通訊傳播委員會（NCC）申訴。
3. **消費爭議**：若屬受理範圍，可向電信消費爭議處理中心查詢調處；適用業者、程序與條件以當時官方說明為準。

## 官方查證來源

- NCC 申訴流程：https://api.ncc.gov.tw/chncc/app/artwebsite?id=450&module=artwebsite&serno=null
- [電信消費爭議處理中心](https://web.tcmc.tw/)（2026-11-02 已查核服務範圍說明）
- 數發部海纜障礙公告（用來比對時間，不能直接當成你的故障原因）：https://moda.gov.tw/major-policies/subseacable/fault/1749

## 報修用語範本

見 `scripts/netdiag.py report` 產生的報告末段。只陳述可驗證的事實，請對方檢查線路與互連品質，並提供案件編號。
